# Contributing

Thanks for taking the time! These are small projects maintained by one person in their
spare time, so a few things make life easier for both of us.

## Reporting a bug

Open an issue with the **Bug report** form. The most useful things are:

- what you did, step by step,
- what you expected and what happened instead,
- the version (release tag or commit) and your system (OS, browser, board),
- logs, screenshots or a diagnostics file if the project offers one.

## Suggesting a feature

Open an issue with the **Feature request** form and describe the problem you want solved,
not only the solution — there may be a simpler way.

## Pull requests

- For anything bigger than a typo, please open an issue first so we can agree on the approach.
- Keep a pull request to one topic.
- Run the project's tests before you push (the README says how); CI runs them too.
- Documentation is in English.

Some repositories have their own `CONTRIBUTING.md` with project-specific rules — that one wins.

## Security issues

Please do **not** open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).
